贝翰战略咨询 · 客户反馈工作台
开始使用  |  1.0.0  |  macOS

一、选择下载
从 GitHub Release 下载“客户反馈工作台-1.0.0-macOS.zip”。面向 macOS 14 或更高版本的 Apple 芯片与 Intel 64 位 Mac。建议使用当前版本的 Safari 或 Chrome。同一个 ZIP 内含两套运行时，启动文件会自动选择。首次启动和日常使用均可离线。

二、完整解压并启动
在访达中双击 ZIP，打开解压所得的整个文件夹；可移到“文稿”等固定位置。
在访达中双击“Start 客户反馈工作台.command”。保留启动窗口；浏览器会自动打开登录页。
若浏览器没有自动打开，把窗口显示的完整访问地址粘贴到浏览器。地址以 http://127.0.0.1: 开头，仅限本机访问。首选端口是 18765，有冲突会自动选用其他端口。
本版未做 Apple Developer ID 签名或公证。从网站下载后若系统要求确认，请先核对发布来源和校验值；企业管理的 Mac 请联系 IT。Apple 说明见 https://support.apple.com/zh-cn/102445 。

三、第一次登录
用户名为 admin。首次启动会为当前操作系统用户生成一套独立的随机密码，显示在启动窗口，也保存在下述数据目录的“首次登录.txt”。保存到密码管理器后可删除此文件。以后使用同一密码；再次双击不会重置密码。请勿把这份文件或数据目录上传到 GitHub。
其他人可以从登录页申请账号；管理员在右上角账号菜单打开“账号审批”，通过后即可登录。界面可切换中文或 English。

四、导入第一份反馈
打开“导入表格”，下载 CSV 模板和填报指南，或直接选择客户自己的 XLSX、CSV、TSV 文件。在预览中指定反馈正文等列，然后创建项目。指挥台显示趋势和待办；“反馈跟进”可设置负责人、期限和处理结果。“反馈抽查”可对照两套名单、核对标签并导出。导出前请核对项目、范围和记录数。

五、关闭、重开与数据
先保存正在编辑的反馈，再关闭启动窗口或按 Ctrl+C。只关闭网页时服务会继续运行。下次打开同一个启动文件即可；已在运行时再次双击会打开已有服务。
数据目录：~/Library/Application Support/Beihan/CustomerFeedback
窗口也会显示实际位置。管理员和审批记录在 auth.sqlite3；反馈项目继续使用浏览器原有格式，并按浏览器和登录账号在 workspace-recovery.sqlite3 保留本机副本。端口改变时，使用相同浏览器配置和账号打开新地址即可继续。请保留站点 Cookie 和浏览器数据，避免用隐私窗口承载长期项目。更换电脑、操作系统用户或浏览器配置，请提前导出需要的明细。
升级时将新 ZIP 解压到单独文件夹，先停止旧版，再启动新版。程序和数据分开存放。备份时请先停止服务，再复制整个数据目录，并保留相应浏览器配置。导出的 CSV 用于交接业务记录，不能还原所有项目规则与历史。
