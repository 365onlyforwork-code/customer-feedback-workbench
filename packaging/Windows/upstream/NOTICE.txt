Windows 随包运行时
==================

本包包含 Python Software Foundation 发布的 CPython 3.14.10 Windows embeddable distribution。
x64 和 ARM64 各自使用对应的原生 Python 解释器。操作系统提供的 Windows 系统 DLL 和 Universal CRT 在 Windows 10/11 中随系统发行。SQLite、Visual C++ 运行库及其他嵌入版依赖已随 CPython 一并提供。各架构目录内的 LICENSE.txt 保留了 Python、第三方组件和 Microsoft Distributable Code 等随附条款；使用和再分发须遵守适用于各组成部分的条款。upstream.spdx.json 为 CPython 官方组件清单。
